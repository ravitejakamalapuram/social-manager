# Privacy policy

Social Manager is a personal tool that one owner runs on their own Google account to post their own videos.

- It reads only the Google Drive files the owner names in a post (the video, thumbnail and captions), and only to upload them.
- It uses the YouTube Data API to upload videos and set their details on the owner's own channel. It stores the YouTube sign-in token in the owner's own Apps Script project, nowhere else.
- It keeps a log of its jobs in a Google Sheet in the owner's Drive.
- It shares no data with anyone, sells nothing and shows no ads.
- The owner can revoke access at any time at https://myaccount.google.com/permissions.

Social Manager's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also follows the YouTube API Services Terms of Service: https://www.youtube.com/t/terms. Google's privacy policy: https://policies.google.com/privacy.

Questions: open an issue in this repository.
